# Yoosal WhatsApp Automation
Test-only Meta WhatsApp Cloud API bot and authenticated enquiry dashboard.
## Reliability
Inbound message IDs are claimed in Postgres. Conversation state, submitted lead, history and a dispatch record are committed atomically before any Meta API call. Duplicate inbound events cannot advance the conversation or start a second dispatch. If an API response is ambiguous (timeout, crash, or upstream 5xx), delivery is marked uncertain; it is not blindly resent. The dashboard displays accepted/sent/delivered/read/failed/uncertain statuses and operational alerts. Meta callbacks reconcile outgoing messages using a random correlation UUID or Meta message ID. A definite interactive-format rejection may use a numbered-text fallback.
## Retention
Supabase Cron job yoosal-bot-maintenance runs every ten minutes. Unfinished sessions and processed inbound IDs are removed after 30 days; chat history, delivery records and alert records after 90 days. Submitted leads and team notes are retained. Stuck dispatches are marked uncertain after five minutes and flagged.
## Setup and production gates
Keep all private environment variables in Vercel; never put credentials in this repository. Callback: https://yoosal-whatsapp-bot.vercel.app/api/webhook, subscribed to messages. Dashboard: /dashboard.html; owner signs in with a confirmed, explicitly allowed Supabase Auth account. Run npm test locally.
The active deployment still uses the shared test project's service-role key. Before commercial production, provision an isolated Supabase project or migrate to a dedicated restricted database role; keep the current test project and other applications intact. A long-lived Meta system-user token must be issued by the business administrator and set in Vercel. Do not connect the business number until the end-to-end customer journey, dashboard access, delivery callbacks and credentials have been verified. Outbound delivery is not guaranteed to be exactly once across an external API boundary; ambiguous sends require human review rather than blind retries. Commercial hosting must comply with provider terms.
